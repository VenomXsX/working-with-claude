# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Spring Boot 3.2 / Java 17 JSON API (plain Spring JDBC, Flyway, no JPA) plus a vanilla-JS dashboard in `src/main/resources/static/`. `workshop/`, `docs/tickets/`, `wall/` and `gift/` are not app code.

- Run: `SPRING_PROFILES_ACTIVE=demo ./mvnw spring-boot:run` (H2, no Docker), or `docker compose up -d db && ./mvnw spring-boot:run` (Postgres).
- Test: `./mvnw test` (one: `-Dtest=Class#method`) and `npm test` (one: `npx jest path/to/file.test.js`). No linter or build step.
- All SQL is in `DashboardRepository`/`VendorRepository`; controllers just call `DateRange.resolve(from, to, clock)`. Metric definitions are in the `DashboardRepository` header comment.
- "Today" is pinned to 2026-09-21 (`ClockConfig`, `ops.today`); never use the machine date. The frontend gets it from `/api/health`.
- `DateRange` deliberately has no validation (bad date = 500, see TODO-232); `DashboardControllerTest.malformedFromCurrentlyProducesA5xx` asserts that.
- `V2__seed.sql` is generated by `tools/make_seed.py`; edit the generator. Expected numbers are in `docs/data/ANSWER-KEY.md`.
- Jest runs `app.js` in jsdom against a fake `/api` in `src/test/javascript/setup/loadApp.js`; every `id` in `index.html` must be in its `REGISTERED_IDS`, and its fixtures must match the Java JSON shapes by hand.
- `pom.xml` dependencies are frozen (needs a CHG ticket).
